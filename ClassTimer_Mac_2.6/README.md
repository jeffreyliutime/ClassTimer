# ClassTimer 2.6 · Mac 原生工程

这个 Xcode 工程以存档的 Swift 原型为基础，参考 Mac 2.5 安装包与 Windows 2.5 的行为重新实现。目标为 Apple Silicon、macOS 15 或更新版本，延续 Mac 2.5 的应用标识和图标。

## 本版功能

- 倒计时、秒表、时钟、一次性闹钟。
- 多段倒计时，每段可设置名称、小时、分钟和秒。支持增删、自动换段、循环和加减一分钟。
- 至少两段时，加减一分钟右侧显示「进入下一段」。正在计时或暂停时可点击。最后一段置灰。
- 本地计时方案可另存、更新、加载和删除。尝试读取兼容的 2.5 方案文件，无法识别的旧文件会保留。
- 讲师窗口、学员悬浮窗、提醒文字、主题、独立投影屏幕、学员窗口尺寸与全屏、菜单栏控制。

## 构建和核对

在有 macOS 15 SDK 的 Apple Silicon Mac 上，打开 `ClassTimer.xcodeproj`，选择 ClassTimer 方案并点击 Run。也可以从工程目录执行 `./Build-Mac.sh`，先运行计时逻辑测试，再生成本机测试用 `.app` 和 ZIP。

计时核心已通过 Swift 测试，全工程源文件通过语法检查。AppKit 和 SwiftUI 窗口、投影、旧版方案实机读取和应用签名仍需在目标 Mac 上核对。
